How To Add New Measurement Labels Later

A. Summary blueprint (pattern_summary.svg)

  1. Add target_<name> anchor in the SVG (green circle).
  2. Register in PATTERN_SUMMARY_MEASUREMENT_TARGETS (patternSummaryMeasurementOverlay.ts).
  3. Wire HTML chip with data-measurement-target in measurements page scripts.
  4. Use bindPatternSummaryOverlayPositioning() — avoid hard-coded CSS coordinates on desktop.

B. Pattern tab / print schematics (diagram-*.svg)

  1. Add {{NEW_TOKEN}} in the SVG at the label position.
  2. Map value in buildSleevelessGarmentDiagramReplacements().
  3. For shoulder bind-off stitches, use a new token — do not reuse {{SHOULDER_STS}} (cross-back width).
  4. Add tests in sleevelessGarmentDiagramReplacements.test.ts.

C. Japanese notation (diagram-jp-*.svg)

  1. Add {{jp-…}} or {{rc-…}} placeholder (keep contiguous in Illustrator).
  2. Register in JP_BACK_NOTATION_SVG_TOKEN_KEYS if new.
  3. Populate in back/front Japanese notation builders.
  4. Extend notation tests for full SVG token coverage.

D. New diagram variant

  1. Add paired diagram-* and diagram-jp-* files.
  2. Add URL constants and routing in diagram src modules.
  3. Update routing tests.
General rules Use target_* for blueprint overlays; {{…}} for schematic text. Never guess coordinates for shoulder stitch labels — add explicit placeholders in the SVG.

Top files for shoulder stitch labels

  1. public/images/patterns/sleeveless/diagrams/diagram-*.svg — add placeholder
  2. sleevelessGarmentDiagramReplacements.ts — wire value (shoulderStitchesPerSideForDiagram())
  3. sleevelessBackJapaneseNotation.ts / sleevelessFrontJapaneseNotation.ts — if JP notation
  4. sleevelessGarmentDiagramReplacements.test.ts — tests

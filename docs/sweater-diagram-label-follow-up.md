# Sweater diagram label follow-up

This is separate work. Do not change these labels in the saved-measurement release.

Stitches & Rows diagrams do not use one rule for the measurement beside a count.

- Sleeveless body diagrams, Drop Shoulder body diagrams, and Set-In Sleeve sleeve diagrams pair the stitch or row count with the requested finished measurement. Inches snap to the nearest quarter inch. Centimeters snap to 0.1 cm.
- Drop Shoulder sleeve stitch labels use the knitted width of the rounded stitch count (stitches divided by gauge). The editor still shows the requested finished cuff and upper arm. Sleeve length rows use the finished length. The sleeve-body row span has no measurement beside it.
- The Set-In Sleeve cap sentence prints the knitted height of the cap rows to the hundredth of an inch. The diagram starts from that same height and then applies the quarter-inch display, so 5.86 in in the sentence appears as 5.75 in on the diagram, and 6.57 in appears as 6.5 in. The row count is the height to knit.

When this is picked up, use one pairing: show the knitted size of the count (count divided by gauge, to one decimal) beside every stitch and row count. Keep requested finished sizes in the editor and in the written measurement lines. That is already how the Drop Shoulder sleeve stitch labels work.

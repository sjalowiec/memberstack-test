Pattern Access Rules (Launch)
** last updated july2, 2026 ***

This document defines the business rules for pattern access and takes precedence over implementation assumptions. If code behavior differs from this document, treat the document as the intended behavior and report the discrepancy.
Anonymous
- Browse pattern builders.
- Explore options.
- Cannot generate patterns.

Free Account
Hat
- Unlimited create.

Blanket
- Unlimited create.

Sweater Systems
- One free Quick Pattern per system.
- Automatically saved.
- May reopen.
- May print/download.
- Cannot edit/customize.

Paid Pattern (future)
- Unlock editing for that pattern.

Member
- Unlimited patterns.
- Unlimited editing.
- Unlimited saved projects.
- Access to all pattern systems.
